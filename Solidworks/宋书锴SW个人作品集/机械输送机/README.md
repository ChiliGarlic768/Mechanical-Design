# 机械输送机 SolidWorks 参数化建模项目

## 项目简介

本项目为机械输送机的 SolidWorks 参数化建模练习，主要内容包括输送带、主动辊、从动辊、侧梁、端盖、机架、电机安装结构以及总装配体的建模与装配。

该项目主要用于记录个人 SolidWorks 学习过程，并作为机械设计、输送线建模和参数化建模方向的作品集展示。

## 建模内容

本次练习主要完成以下内容：

- 机械输送机主要零件建模
- 输送带、主动辊、从动辊等核心传动部件建模
- 侧梁、端盖、支撑钣金、机架等结构件建模
- 电机、电机安装板、链轮、链条等驱动结构整理
- 带座轴承、脚杯等标准件建模与装配
- 机械输送带总装配体搭建
- 参数化尺寸关系与方程式设置
- 装配关系检查与整体结构展示

## 项目结构

本模型主要由以下几个部分组成：

| 模块 | 说明 |
|---|---|
| 输送部分 | 包括传送带、主动辊和从动辊等核心输送部件 |
| 驱动部分 | 包括电机、电机安装板、链轮和链条等动力传递部件 |
| 支撑部分 | 包括机架、侧梁、支撑钣金和脚杯等支撑结构 |
| 端部结构 | 包括动力端端盖、从动端端盖等封闭与保护部件 |
| 标准件部分 | 包括带座轴承、链轮、脚杯等标准件或外购件 |
| 参数化部分 | 通过尺寸参数和方程式控制输送机的主要结构尺寸 |

## 建模流程

本项目主要参考参数化输送线建模流程，建模顺序如下：

1. 基本结构介绍
2. 输送带建模
3. 主动辊与从动辊建模
4. 侧梁建模
5. 端盖与支撑板建模
6. 机架与脚杯建模
7. 动力结构建模与电机选型
8. 方程式与参数化尺寸设置
9. 总装配体搭建与装配关系检查
