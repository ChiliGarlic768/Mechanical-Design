## 建模内容

本次练习主要完成以下内容：

- 行星减速器主要零件建模
- 齿轮、轴、轴承、挡圈、密封圈等零件整理
- 行星架、太阳轮轴、外壳等子装配体搭建
- 行星减速器总装配体搭建
- 装配关系检查与整体结构展示

## 学习收获

通过本次建模练习，主要熟悉了以下内容：

- SolidWorks 零件建模流程
- 轴类、齿轮类和壳体类零件的建模思路
- 标准件在装配体中的使用方式
- 行星减速器的基本结构组成
- 多零件装配体的层级管理方法
- 机械传动结构的整体建模与展示

本项目主要用于个人 SolidWorks 学习记录和机械设计作品集展示，后续可继续补充爆炸图、工程图、装配过程截图和结构说明。
